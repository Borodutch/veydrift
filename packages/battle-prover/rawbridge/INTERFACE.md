# Raw bridge interface (additive; no old qualification ABI changes)

Step.Statement() [5] public fields: [Binding,BeforeHash,AfterHash,Result,KindPublic]. Kind is compile-time authenticated shape and constrained equal to KindPublic: Begin0, Source1, Row2, Seal3. Shape(kind) fixes path count; no witness-controlled circuit expansion. All hash domains below use standard BN254 MiMC H(d,v)=MiMC(d,len(v),v...). Legacy Keccak is standard gnark sha3.NewLegacyKeccak256; no custom permutation/hints.

Binding=H441001(preparation.Context values,Version4,Codehash4,Engine4,RequestID4,Purpose4). Context ordering exactly matches existing preparation. Its Identity.Catalog/Rules are bytes32 IDs of the new linked qualification release; old qualification uses different labels and remains unchanged.

State commitment H441002 binds Started,Done,Raw,Tech,Sources,LastType,Remaining,Side,Journal4,Rows4,SourceID4,Owner4,Counts16. Journal is the full256 Keccak digest as four LE64 limbs, never reduced into Fr. Counts are uint32, remaining is uint36; row count and source ID full256. This explicit State is the resumable checkpoint. It is advice until BeforeHash equals a previously VERIFIED prefix AfterHash. No state may be resumed solely from a host assertion.

Begin starts exact Initial(): empty depth256 preparation Raw/Tech/Sources trees, zero journal/rows/source/counts, resident side1. It constrains the exact16 ABI header words with Solidity widths, binds body/moon/generation/impact to preparation.Identity, rejects blocked, requires recorded generation for moon, and retains resident owner. Initial Keccak is exact Solidity dynamic bytes tuple encoding with 13-word head, header offset416, header length512. Source ABI is exactly32 static FleetMission words, including14 MissionShips and omitted satellite/crawler positions; dynamic source-event offset128,length1024. Independent Foundry cast tests validate these lengths/tuple offsets, source bytes, header bytes, all row tuples and final Keccak.

Source requires prior source remaining count0, nonzero previously absent source ID in a complete sparse tree, inserts source membership, hashes exact source event, and records owner/14 ship counts/side. Every positive source lane must be consumed exactly once before next Source/Seal. Mission type Attack3/AcsAttack8 sets side0; other journaled mission types side1. The chain journal remains authority for chronology/membership eligibility; this is a constrained conversion, not a reexecution of every game eligibility predicate.

Row requires exact current source/owner/side, positive uint32 count, type0..23 and strictly ascending type within each source. Nonresident quantity must match the corresponding MissionShips lane. Resident counts are authenticated directly by their chain-journal records; no invented resident FleetMission. Raw insertion uses monotonically incrementing full256 row index, proves old leaf0 and updates full depth256 tree with preparation.RawDomain row encoding. Owner-tech insertion proves previous leaf absent or EXACT same tech hash, updates complete Tech tree. These properties reject duplicate source/type, duplicate sources and conflicting per-owner research; no omitted tree leaves can enter because roots begin empty and every update is proved.

Seal requires all source counts consumed and Raw/Tech/rowCount equal Meta.Preparation, then computes exact chain snapshot=Keccak(abi.encode(previous,uint8(3),rows)), sets Done and Result=H441003(Binding,snapshot4). Result is zero for every other kind. No transition after Done; Begin cannot reset a noninitial state.

AssertLinked compares Binding and prior AfterHash=next BeforeHash and prior Result0. AssertComplete requires same Binding, exact genesis BeforeHash, firstKind Begin,lastKind Seal, nonzero terminal Result. Must authenticate proofs for EVERY edge; cannot authenticate just first/last or skip Source/Row proofs. AssertSealed(api,terminal,meta,snapshot) binds a VERIFIED terminal result to exact metadata and full chain snapshot. Composition must verify complete prefix before calling it.

Build(meta,header,events) is a convenience witness builder, not an authenticator or production unbounded-memory worker. Each generated Step is independently fixed-size. A streaming prover may persist explicit State and three Merkle stores plus verified prefix position and resume; neither a host checkpoint nor a Build result establishes proof validity. DecodeWords enforces exact ABI length; circuits enforce canonical widths and reconstruct hashes, so parsing correctness is not trusted.

## Chain authentication and integration

New qualification.LinkedCircuit consumes this terminal Result and binds preparation.ContextHash, exact pinned catalog/RF, actual per-battle purpose, gated snapshot/randomness context and full256 direct-word seed. See ../qualification/LINKED-INTERFACE.md. It exports Keccak of actual chain fields (not an offchain SHA assertion). Final contract must recompute that public record from authoritative storage while phase3 and compare full256. No contract reads/hashes are magically provided to this circuit.

No production activation, verifier, recursive setup/proof, settlement, or contract edits. Arbitrary-length authenticated recursion and onchain record comparison are remaining parent integration gates. Old qualification SHA receipts and old composition receipts are not evidence for this new schema.
