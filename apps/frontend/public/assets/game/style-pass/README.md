# Veydrift Style-Pass Assets

This directory contains the visible tester subset from the 2026-05-15 regenerated style pass.

- `generated/planets/`: all planet thumbnails used by Galaxy, Planet detail, and management surfaces.
- `generated/buildings/`: mid-tier building cards currently exposed in the playable management catalog.
- `generated/ships/`: ship cards currently exposed by the playable shipyard catalog when a generated preview was available.
- `high-res/small-cargo-alive-fullship-2k.png`: accepted Small Cargo direction anchor; the rejected generated small-cargo preview was not copied.

Defense previews and unshown future gameplay assets are intentionally not wired into the current tester build.
